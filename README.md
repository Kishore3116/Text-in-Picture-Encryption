# 🖼️ Text in Picture Encryption (Steganography)

![Project Banner](https://img.shields.io/badge/Status-Completed-brightgreen) ![Python](https://img.shields.io/badge/Python-3.12-blue) ![Machine Learning](https://img.shields.io/badge/ML-Integrated-orange)

A secure and innovative project that allows you to **hide text inside images** using encryption techniques. This combines **steganography** and **machine learning integration** for enhanced data security and privacy. Perfect for secure communication and digital watermarking applications.

---

## 🔍 Project Overview

This project enables you to embed secret messages into images such that the text is **invisible to the naked eye**. It uses Python to perform encryption and decryption and ensures that your sensitive information remains safe during transmission.

**Key Features:**

* Hide any text inside an image without visibly altering it.
* Extract hidden text from an image reliably.
* Optional integration with machine learning models for pattern recognition and enhanced security.
* User-friendly interface for easy interaction.

## 🚀 How It Works

1. **Encryption & Hiding:**

   * Input your secret text.
   * Select an image to hide the text in.
   * The program converts the text into binary and embeds it into the image’s pixels.

2. **Decryption & Extraction:**

   * Load the image with hidden text.
   * Extract the binary data and convert it back to readable text.

3. **Optional ML Integration:**

   * Use pattern recognition or anomaly detection for secure verification of hidden messages.
